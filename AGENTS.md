# Working on the essays

Read [CONTRIBUTING.md](./CONTRIBUTING.md) for the editorial and publishing conventions. The [README](./README.md) sets the reading order.

For a substantial writing change, use [editorial review](./skills/editorial-review/SKILL.md). Check examples and sources independently; do not present fictional outcomes as observations.

Run `python3 site/build.py --check-text` from the root before submitting a change. It validates the text-only site and reading order. Narration generation is deferred; do not invent or regenerate audio unless that work is explicitly requested.

Before finishing, consider whether a recurring difficulty deserves a small improvement to the repository. Retain evidence and fix the existing route to knowledge before adding a new instruction. The [compounding pass skill](https://github.com/grove/patterns-of-compounding-engineering/tree/main/skills/compounding-pass) offers an optional procedure. A change can finish without a new artifact.
